# How do Registrations, Banks and Playlists work, and can a Playlist choose the starting Registration?
question: How do Registration Memory, Banks and Playlists work, and can a Playlist choose which Registration a Bank starts on?
citations: [OM p.80–87], [OM p.107], [RM p.63], [DL p.47–56]
verified: 2026-09-29

## Claims checked

- **A "Registration" saves the keyboard state: mostly.** Registration Memory saves panel settings such as Voices,
  Styles and effects [OM p.80–81]. When you register, you tick which groups of items to include [OM p.81]. Not
  everything is stored: the Parameter Chart marks 258 settings ○ and 206 × for Registration Memory. For example,
  Transpose is saved but Master Tune is not [DL p.47–56].
- **4 Registrations per Bank: correct.** REGISTRATION MEMORY [1]–[4]. All four are saved together as one Registration
  Memory Bank file [OM p.80, p.82].
- **Unlimited Banks until memory runs out, then external storage: correct in practice.** The manuals state no Bank
  limit. Internal memory is approx. 20 MB, and the external drive is a USB flash drive [OM p.107]. If a registration
  recalls Songs or Styles stored on a USB drive, that drive must be connected when you recall it [OM p.83].
- **A Playlist is a list of Banks: correct, with different terminology.** A Playlist entry is a Record, a link to a
  Bank file. All Records are saved together as one Playlist file [OM p.80]. It is meant for set lists [OM p.84].
- **Switch Registrations during a song: correct.** Press [1]–[4] [OM p.83], or use a Registration Sequence to step
  through them in a set order with TAB [◀][▶] or a pedal [RM p.63].
- **A Playlist chooses the starting Registration: correct.** Each Record has Action → Load Regist Memory, which recalls
  the chosen Registration number when the Record is selected (Off = none). View can also open the score, lyrics or
  text display [OM p.85].

## Terminology
Registration = registered panel setup in Registration Memory, on REGISTRATION MEMORY [1]–[4] ·
Bank = Registration Memory Bank file ([BANK]) · Playlist entry = Playlist Record · Playlist = Playlist file ([PLAYLIST]) ·
starting Registration = the Record's Action → Load Regist Memory.

## Workflow for a show
1. Make one Bank per song:
   1. Set up the panel.
   2. Press [MEMORY] and tick the items to register.
   3. Press [1]–[4] to store the setup.
   4. Save the Bank: [BANK] → [6▼] (Save). [OM p.81–82]
2. Press [PLAYLIST] → [8▲▼] (Option) → [3▲▼]/[4▲▼] (Create New Playlist), then add each Bank as a Record [OM p.84–85].
3. For each Record: [5▲▼] (Edit) → Action → Load Regist Memory = the song's first Registration [OM p.85].
4. Reorder Records with [6▲▼]/[7▲▼] (Move) [OM p.87]. Save with [8▲▼] (Option) → [7▲▼] (Select & Save) [OM p.86].
5. On stage:
   - Select a Record and press [ENTER] to load the Bank and run its Action [OM p.86].
   - Switch Registrations with [1]–[4] [OM p.83] or with a pedal via Registration Sequence [RM p.63].

## Notes
- The four button setups survive power-off [OM p.82].
- Freeze keeps chosen items (e.g. the Style) from changing when you recall a Registration [OM p.83].
- Registration Sequence pedal settings (other than Off) override the pedal's other functions [RM p.63].
