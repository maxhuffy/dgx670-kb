# RM p.46 — Editing Music Notation (Score) Settings

[6▲▼]
Note Name
Selects the type of the note name indicated at the left of the note in the notation from among the following three types. The settings here are available when the Note param- eter above is set to On.

• A, B, C: Note names are indicated as letters (C, D, E, F, G, A, B).
• Fixed Do: Note names are indicated in solfeggio, with the note of C fixed to Do.
• Movable Do: Note names are indicated in solfeggio according to the scale inter- vals, and as such are relative to the key. The root note is indicated as Do. For example, in the key of G major the root note of “Sol” would be indicated as “Do.”
