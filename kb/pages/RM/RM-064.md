# RM p.64 — Calling Up Registration Memory Numbers in Order (Registration Sequence)

5. Program the Sequence order, from left to right.
Press one of the REGISTRATION MEMORY [1]–[4] buttons on the panel, and then use the [4▲▼] (Insert) buttons to input the number. The Cursor position can be moved by using the Cursor buttons [▲][▼][◀][▶].

[FIG RM-064-f1 — Regist Sequence/Freeze display, Registration Sequence tab (Sequence Data programming); see kb/figures/RM-064.md#f1]

Indicates the Registration Memory numbers, in the order of the current Registration Sequence.

7 5 6

[3▲▼]
Replace
Replaces the number at the cursor position with the currently selected Registra- tion Memory number.

[4▲▼]
Insert
Inserts the number of the currently selected Registration Memory number to the cursor position.

[5▲▼]
Delete
Deletes the number at the cursor position.

6. Press one of the [6▲▼]/[7▲▼] (Sequence End) buttons repeatedly to determine how Registration Sequence behaves when reaching the end of the sequence.

• Stop................. Pressing the TAB [▶] button or the “advance” pedal has no effect. The sequence is “stopped.”

• Top.................. The sequence starts again at the beginning.

• Next Bank...... The sequence automatically moves to the beginning of the next Registration Memory Bank in the same folder.

7. Use the [1▲▼] (Seq.) buttons to turn the Registration Sequence function on.

8. Press the [EXIT] button to save the Registration Sequence settings as part of the current Registration Bank file.
When a message appears asking you to change the settings, use the [7▲▼] (Yes) buttons to actually save the sequence data.

NOTICE

Settings in the Registration Sequence display will be lost if you select another Registration Bank without carrying out the Save operation.
