Advanced Features
Refer to the Reference Manual on the website, Chapter 3.

Playing Style with the Smart Chord feature:

[MENU] → Cursor buttons [▲][▼][◀][▶] Split Point/Chord Fingering, [ENTER] → TAB [▶] Chord Fingering → [2▲▼] – [4▲▼] Smart Chord

Learning how to play specific chords (Chord Tutor):

[MENU] → Cursor buttons [▲][▼][◀][▶] Chord Tutor, [ENTER]

Style playback related settings:
[MENU] → Cursor buttons [▲][▼][◀][▶] Style Setting, [ENTER]

Specifying chords with your right hand while playing bass with your left hand:

[MENU] → Cursor buttons [▲][▼][◀][▶] Split Point/Chord Fingering, [ENTER] → TAB [◀] Split Point
