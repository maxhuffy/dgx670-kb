# OM p.20 — Display-based Controls

[1▲▼] – [8▲▼] buttons

The [1▲▼] – [8▲▼] buttons are used to make selections or adjust settings (up or down correspondingly) for functions shown directly above them. In this manual, the upper buttons are described as [▲] and the lower buttons as [▼].

For menus that appear in this section of the display, use the [1▲] – [8▲] (upper) buttons.

[FIG OM-020-f1]

For menus that appear in this section of the display, use the [1▼] – [8▼] (lower) buttons.

For list menus that appear, use the [1▲▼] – [8▲▼] buttons to select the desired item.

[FIG OM-020-f2]

For parameters that appear in slider (or knob) form, use the [1▲▼] – [8▲▼] buttons to adjust the value.

When setting parameters, you can reset the parameter to the default value by pressing both [▲] and [▼] buttons of the same number simultaneously.

Data dial

Depending on the selected display, the Data dial can be used in the following two ways.

■Adjusting parameter values
You can conveniently use the Data dial in tandem with the [1▲▼] – [8▲▼] buttons to adjust parameters indicated in the display.

[FIG OM-020-f3]

Rotate the Data dial to adjust the selected parameter.

Select the desired parameter with the appropriate [1▲▼] – [8▲▼] buttons.

This convenient technique also works well with pop-up parameters such as Tempo and Transpose. Simply press the appropriate button (ex., [TEMPO/TAP]), and then rotate the Data dial to set the value.
